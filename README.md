# Generador de portadas · TecnosZubia Oposiciones

Aplicación web de un solo archivo (`index.html`) para crear portadas de temas.

1. Arrastra un documento Word (`.docx`) con el formato de portada.
2. Se rellenan automáticamente los campos: especialidad, nº y título de tema, revisión y curso.
3. Edita lo que necesites y pulsa **Descargar PDF**.

Funciona 100% en el navegador, sin servidor ni dependencias.
